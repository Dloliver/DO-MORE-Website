# Do More ATL Portfolio

React + Vite + Tailwind CSS portfolio prototype for domoreatl.com.

## Run locally

```bash
cd do-more-atl-portfolio
npm install
npm run dev
```

Open the localhost URL shown by Vite, normally:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview
```

## Links to update before launch

In `src/App.jsx`, replace placeholder `#` links for SwipeTheVote and Perfect 5 with their live URLs.

## Deployment

This project is ready for GitHub and Netlify. Netlify settings:

- Build command: `npm run build`
- Publish directory: `dist`
